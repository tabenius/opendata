# Vendored rbq contract

`rbq-repository.v1.json` is copied verbatim from
[tabenius/rebsync](https://github.com/tabenius/rebsync) at commit
`8023dcb7e49f1577b9bc639ea9c3773ba06f09ba` (`contracts/rbq-repository.v1.json`).
rebsync owns it. Do not edit; update by copying a new pinned version and
regenerating `SHA256SUMS` (`sha256sum rbq-repository.v1.json > SHA256SUMS`).

CI checks the checksum, and `packages/rbq` tests every vector in the file.
